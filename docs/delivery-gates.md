# Prototype delivery checks

This repository follows the platform's [standing owner delegation](https://github.com/aloerch/ambisgis-platform/blob/7812efa3502ec1d7004b485d35b433eea56ce13e/plan/authorizations/2026-10-02-standing-delegation.md) and [delivery policy](https://github.com/aloerch/ambisgis-platform/blob/7812efa3502ec1d7004b485d35b433eea56ce13e/plan/docs/standing-delivery-policy.md). The integrator verifies `aloerch`, repository ID `1376927417`, current refs and exact review/test evidence before any remote change. Only normal protected PR merges are allowed.

The reviewed `prototype-reference` workflow runs on pull requests targeting and pushes to `ambisgis/main`. It fetches the exact public owned source SHA and runs the twelve independent reference examples and three dependency-free DB01 schema/identity guards using the runner's checked Python 3.12. The DB01 addition is one unittest command; triggers, source verification, runner, timeout, concurrency and permissions are unchanged. It has empty token permissions, no external actions, secrets, package installation, artifacts, cache, deployment, publication or merge step. It cannot satisfy real database acceptance. [Local equivalent-command evidence](../evidence/db01/ci-equivalent.json) does not claim a hosted run; DB01's 22 actual database tests and the independent security probes remain mandatory separate gates.

The required `owned-database` status is posted by the trusted integrator only after exact-source real PostgreSQL/PostGIS tests pass using retained owned binaries. The required `delegated-review` status represents separate-context scrutiny of the actual source/tests/acceptance and final evidence. The platform gate runs from trusted baseline bytes outside this candidate repository, with private policy and transcript hashes. It also requires the actual commands, logs, final base/head and all applicable source and benchmark evidence. Shared account automation is never represented as a second GitHub approving identity.

Before this increment the repository's verified default `main` was initial commit `41fbb62b9967fc3409aa60a960823b7747f76523`, containing only README.md, with no inherited workflow. Establishing absent `ambisgis/main` at that exact initial commit preserves `main` and history. The default may move only after source/workflow review. Required checks become mandatory only after successful observed runs. Force pushes, deletion and administrator bypass remain forbidden. The integrator records actual settings and mutation results separately; this document is the intended audited configuration, not a claim that pending remote changes have occurred.
